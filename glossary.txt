# CÓMO FUNCIONA / HOW IT WORKS
#   1. La regla se inyecta en el prompt SOLO en los lotes que contienen el término.
#      The rule is injected into the prompt ONLY for batches containing the term.
#   2. Después, si el modelo dejó el término SIN traducir, se reemplaza automáticamente.
#      Afterwards, if the model left the term untranslated, it is replaced automatically.
#   NO puede arreglar un sinónimo mal elegido (p. ej. "Parcela" en vez de "Contingente"):
#   para eso usa  --audit-spanish  y luego  --purge-audited  para retraducir esas cadenas.
#   It canNOT fix a wrong-but-translated synonym; use --audit-spanish + --purge-audited.
#
#   Cambiar este archivo NO invalida el caché: lo ya traducido conserva su texto.
#   Editing this file does NOT invalidate the cache; already-cached strings keep their wording.
#
# ANTES DE AÑADIR UN TÉRMINO, LEE LA CADENA INGLESA COMPLETA.
# BEFORE ADDING A TERM, READ THE FULL ENGLISH STRING.
#   "Allotment" se tradujo como "Parcela" porque parece un terreno, pero el inglés dice
#   "Allotments quickly train armies of units" y "Allotments contain more units": es un
#   BLOQUE DE TROPAS. Traducir por el sentido equivocado confunde más que no traducir.
#
# Las líneas que empiezan con # se ignoran. / Lines starting with # are ignored.
#
# CONDICIONES POR CONTEXTO / PER-CONTEXT CONDITIONS
#   Una palabra inglesa puede necesitar dos términos distintos según el contexto. Se añaden
#   condiciones separadas por "|" antes del "=", y se comprueban contra el TEXTO INGLÉS:
#     Termino | si:TEXTO = destino     ("si:", "solo si:", "if:", "only if:")  exige TEXTO
#     Termino | no:TEXTO = destino     ("no:", "not:", "unless:")              prohíbe TEXTO
#   Ejemplo real (ya resuelto en el código, aquí solo como muestra de la sintaxis):
#     Skirmisher | si:<color=0.07, 0.68, 0.17> = infantería a distancia
#     Skirmisher | no:<color=0.07, 0.68, 0.17> = Hostigador
#   A word may need two different terms depending on context; conditions are checked against
#   the ENGLISH source text.

# Bloque de tropas reclutado de una vez (sistema sueco de asignación militar).
# NO es una parcela de terreno: el Torp y el Rusthåll son los edificios, esto es la tropa.
Allotment = Contingente

# Cuerpo de élite del Círculo de Ossus ("the Circle's elite soldiers").
Boneguard = Guardia Ósea

# Unidad de infantería de leva. "Conscripto" es el término latinoamericano.
# OJO: como VERBO ("Conscript Sepoys") es "reclutar"; el motor ya lo protege.
# NO usar "Recluta": es el nombre de otra unidad distinta ("Recruit").
Conscript = Conscripto

# "Skirmisher" NO se pone aquí: son DOS cosas distintas según el color de la etiqueta.
#   Dentro de <color=0.07, 0.68, 0.17> es la CLASE de contraataque, la que el motor imprime
#   como "Infantería a Distancia" (_locID 430207)  ->  "infantería a distancia"
#   Fuera de la etiqueta es la unidad que se llama Skirmisher          ->  "Hostigador"
# Una carta que decía "hostigadores" mientras el tooltip decía "Infantería a Distancia" hizo
# creer que la Legión Peruana (infantería de línea) no recibía el bono que sí recibe.
# Las dos reglas viven en COUNTER_KEYWORDS y SPANISH_GLOSSARY (translate_gemini.py) porque
# necesitan el código de color y correcciones deterministas. Si alguna vez hiciera falta
# expresarlo aquí, la sintaxis con condición de abajo lo permite.

# Héroe tipo Explorador de las civilizaciones de Oriente Medio.
Warlord = Caudillo

# Título otomano pegado a un nombre propio: "Muhammad Ali Pasha", "Ali Pasha".
Pasha = Pasha

# Edificio de investigación islámico. Forma recogida por la RAE.
Madrasah = Madrasa

# Combatiente irregular balcánico. Nombre propio, no se traduce.
Hajduk = Hajduk

# Unidad invocada. Concuerda con "Righteous Army" = "Ejército Justo".
Righteous Fighter = Guerrero Justo

# La Hunter's Lodge / Hunting Lodge: cabaña de caza.
# NO es "Logia" (eso es la logia masónica).
Lodge = Cabaña

# Formación de infantería en cuadro. "Spanish Square" es el Tercio Español.
# NO es "Plaza" (eso es una plaza urbana) ni "Cuadrado" (la figura geométrica).
Square = Cuadro

# Etnónimo. Ambas formas son válidas en español; se fija la mayoritaria.
Zapotec = Zapoteca

# OJO, "revolt" tiene TRES sentidos en este archivo y solo uno estaba mal:
#   verbo, la mecánica de Revolución  -> "sublevarse"   (era "revolverse", incorrecto)
#   sustantivo, levantamiento con nombre -> "Revuelta"  ("Arab Revolt" = "Revuelta Árabe") CORRECTO
#   adjetivo "revolting" = repugnante                                                      CORRECTO
# Y "Revolver" es además el arma (Colt Revolver = Revólver Colt): no tocar.
Revolt = sublevarse
